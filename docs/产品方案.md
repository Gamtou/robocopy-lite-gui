# Robocopy Lite 产品方案

## 首页和任务

用户双击便携 EXE 启动。首页的任务列表同时展示自建任务和外部 Robocopy。自建任务显示名称、路径、同步模式、状态和上次同步时间。新建时选两个文件夹和模式，可保存或保存并开始。一个任务有固定 ID。重复监测、补扫和执行都留在原任务下，执行记录和日志在任务详情查看。

| 操作 | 行为 |
|---|---|
| 开始 / 继续 | 核对两个文件夹，立即补同步，之后持续监测文件变动。执行完成后回到监测状态。 |
| 暂停 | 停止监测、排队和本任务的 Robocopy。保留已写入的内容，继续后重新扫描。 |
| 编辑 | 暂停后可改名称、模式、路径和高级设置。改路径时展示原路径及当前选择，重新校验后保存。改到新目标时，旧位置保留。双向任务重新建立配对。 |
| 取消并删除任务 | 确认后停止同步并删除任务配置。两边已有文件全部保留。 |
| 预览 | 暂停的单向任务可用 Robocopy 查看拟执行内容，在日志中查看结果。 |

文件夹断开、离线或指向的位置改变时，任务自动暂停并记录原因。重新接入后仍需手动点「继续」。退出或重启应用也保留暂停状态。

### 外部任务

| 操作 | 行为 |
|---|---|
| 暂停并接管 | 路径可读时，确认后保存为暂停的单向累计备份，并结束原 Robocopy。点击「继续」后按该任务的配置补同步并持续监测。 |
| 编辑并接管 | 预填能读取的路径，允许修改两个文件夹及同步模式。路径不可读时可手动填写。确认保存后，应用结束仍在运行的原进程。 |
| 取消 | 确认后只结束选中的外部 Robocopy。已写入的文件保留，正在写入的文件可能不完整。 |

接管后的任务使用面板上的同步配置。外部命令的镜像、删除、移动等参数不会沿用。Windows 拒绝操作或进程身份已变更时，界面提示错误。

## 备份进度和日志

- 任务卡显示本轮用时。单向任务显示估算字节数和文件数，复制中还可显示速度及预计剩余时间。双向任务的速度和预计剩余时间针对当前文件。
- 失败记录从 Robocopy 完整日志提取 Windows 原因、失败文件总数和部分路径，当退出码仅是汇总结果时，可在日志页展开查看。
- 同步中的任务卡显示进度条和当前文件路径。单向任务按本轮预先扫描的字节数估算总进度，另显示当前文件的百分比。双向任务显示本轮处理项数与复制中的文件。扫描或无法取得总量时显示活动状态。
- 外部 Robocopy 提供可读的日志时，显示日志报告的文件与可用的文件进度。进度显示受其启动参数和日志权限影响。
- 首页「日志」进入运行记录，可按任务、状态及关键词查找。详情显示时间、来源、目标、最近报告的文件、错误与 Robocopy 输出，也可打开本机日志文件夹。

## 同步模式

每个任务可在「规则设置」勾选常见系统杂项，包含 `.DS_Store`、`._*`、`Thumbs.db`、`desktop.ini` 和 `__MACOSX`。也可选择过滤所有点号开头的项目，或者按扩展名和自定义名称规则排除。预设默认关闭。

| 场景 | 单向累计备份 | 双向同步 |
|---|---|---|
| 新增、修改 | 来源自动写到备份位置，备份端改动不会写回。保留目标端较新的同名文件。 | 任一侧新增文件、或修改上次已同步的文件，变化同步到另一侧。 |
| 删除、改名 | 删除来源文件后，备份保留。改名后的新名字会同步，旧备份保留。 | 单边删除保留对端原件。改名按新增和删除分别判断，旧名字可能在对端保留。 |
| 同名冲突 | 同时间戳但大小不同的文件按增量复制规则处理。 | 首次配对的同名异内容，或上次确认一致后两侧都改过的文件，保留原件并列入冲突。用户可选「保留左侧」「保留右侧」「两份都留」。 |

双向任务遇到同名冲突时，其他互不冲突的文件继续同步。「两份都留」会在两侧保留右侧带区分后缀的副本，再统一原文件名。单边删除后，如果对端仍是上次同步的版本，已删除的一侧维持删除。对端有新版本时视作修改，会同步回来。

## 托盘和设置

窗口与托盘使用 🔄️ 图标。关闭窗口时默认缩到托盘，同步继续运行。托盘提供「打开面板」和「退出」。退出后所有应用内任务停止监控和复制。重开时恢复此前已启用的任务，自动暂停和手动暂停的任务维持原状态。

首页设置管理登录启动、关闭窗口到托盘和错误通知。任务高级设置管理断点续传、速度和排除规则。

## 验收场景

- 只创建一条 `test`，分多批写入临时目录，任务保持同一个 ID。
- 暂停期间加入新文件，继续时补同步。编辑目标后，新目标收到文件，旧目标完整保留。取消任务后两边已有文件保留。
- 模拟盘符或目录断开、恢复和应用重启。恢复后仍需手动继续。
- 验证双向的左右新增与修改、首次同名冲突、两侧同时修改、保留两份，以及单边删除。
- 验证关闭窗口后托盘仍运行，真正退出后本应用启动的 Robocopy 进程随之结束。
